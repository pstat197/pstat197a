An alternative analysis

Our earlier approach separated:

  1. selecting proteins
  2. fitting logistic regression using the selected proteins

LASSO combines variable selection and coefficient estimation.

It is useful here because we have many more candidate proteins than subjects.

LASSO: brief review

For logistic regression, penalize the negative log-likelihood:

\[ (\hat{\beta}_0,\hat{\beta})= \arg\min_{\beta_0,\beta} \left\{-\ell(\beta_0,\beta;x,y)+\lambda\sum_{j=1}^{p}|\beta_j|\right\}. \]

  • The penalty shrinks coefficients and can set some exactly to zero

  • Larger \(\lambda\) generally produces a sparser model

  • The intercept is not penalized

Treat this as review for students who took PSTAT 131. The reference slides provide a toy example and further explanation for those who need it.

Selecting the penalty

Use cross-validation within the training data to compare penalty values.

  • lambda.min: smallest mean cross-validated loss

  • lambda.1se: largest penalty within one standard error of that minimum

For this example, use lambda.1se and then evaluate the chosen model on the held-out test set.

The test set does not choose the penalty or the proteins.

The biomarker workflow

  1. Split subjects into training and test sets

  2. Use training data to tune the penalty and fit the LASSO classifier

  3. Examine which proteins have nonzero coefficients

  4. Evaluate the chosen model on the held-out subjects

Scaling and other learned preprocessing belong inside the training procedure.

This is the handoff point. Feel free to use this familiar analysis if it is helpful. The complete example is in the reference section.

Some final thoughts

  • Reproducing a computation and validating a predictive model address different questions

  • Similar prediction accuracy can accompany different selected protein panels

  • A small test set gives an uncertain estimate of future performance

  • Neither variable selection nor classification accuracy alone establishes diagnostic usefulness
